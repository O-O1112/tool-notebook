# 介面極簡化與字彙歸位降噪重構計畫 (UI Cleanup & Text Realignment Plan)

## 1. 深度問題診斷：畫面繁雜與「字彙跑錯地方」的具體癥結

針對您指出的「畫面好繁雜又亂，然後字彙跑錯地方」，經過嚴格排查，定位出以下 3 處核心失誤：

1. **管理與協作字彙跑進了工具搜尋列 (Misplaced Vocabulary in Search Bar)**：
   - 原本屬於空間層級的「發布代管」、「團隊成員」、「團隊對話」、「AI 代寫」、「投影簡報」等 6 個詞彙與大按鈕，被**錯誤放置在工具過濾列**（與「全部、自訂程式、Iframe」混在一起）。
   - 當按鈕過多時，CSS `flex-wrap` 觸發折行，導致這些協作字彙直接**掉到第二行、覆蓋在標籤列與背景飾紋上方**，形成字樣跑位與重疊雜亂。

2. **頂部導覽列按鈕擠壓導致文字斷行與位移 (Navbar Squeeze & Text Collision)**：
   - 頂部導覽列橫向硬塞了 13 個按鈕，在一般筆電或非 4K 螢幕下，寬度直接爆表。
   - 導致左側的「邀請碼: SPC-XXXX」、「空間名稱」、「擁有者」與右側的「發布代管」、「團隊成員」、「團隊對話」產生嚴重推擠，甚至文字被迫垂直折行或字樣被切掉。

3. **小工具卡片頭部 9 顆按鈕把「標題字樣」擠到不見或變形 (Card Header Title Squashed)**：
   - 每一張卡片頭部橫排塞了：拖曳把手 + 狀態圓點 + 標題 + 置頂標籤 + 類型標籤 + 調色盤 + 更多 + 釘選 + 彈出 + 1x/2x文字 + 重新整理 + 編輯 + 全螢幕 + 刪除。
   - 9 顆按鈕佔去 240px 以上寬度，導致卡片標題字彙只剩 2~3 個字的空間，在切換不同螢幕寬度時「置頂」與「1x/2x」文字還會忽隱忽現，造成字彙跳動錯位。

## 2. 徹底解決方案：字彙歸位與四維視覺降噪

### 步驟 1：字彙歸位與次導覽列純淨化 (`SpaceLayout.jsx`)
- **徹底移除錯置的 6 個大字彙**：
  - 將「發布代管」、「團隊成員」、「團隊對話」、「AI 代寫」、「投影簡報」從工具篩選列完全移除！
  - 移除背景 `SpaceStationeryBannerDoodle` 飾紋，徹底消除文字與插畫重疊問題。
- **次導覽列回歸純粹的內容搜尋與分類**：
  - 左側：純粹的搜尋框（搜尋小工具名稱或 #標籤）。
  - 右側：精準的 3 顆分類膠囊（全部、自訂程式、Iframe 視窗）+ 「範本專區」 + 「批次選取」。
  - 保證單行排列，**永遠不觸發折行錯位**。

### 步驟 2：頂部導覽列結構化整合與文字保護 (`Navbar.jsx`)
- **左側字樣空間保護**：
  - 空間名稱 + 邀請碼標籤固定寬度與 `whitespace-nowrap`，禁止折行。
  - 身分徽章（擁有者 / 協作者）精簡為微型圓點指示器，避免佔位。
- **右側操作聚合收納 (從 13 個按鈕縮減為 4 組)**：
  1. **排版切換組**（Shelf, Wall, Grid, Tabs, Collapsed）
  2. **搜尋與指令面板** (`Ctrl K`)
  3. **協作與發布整合選單 (Team & Hosted Portal Menu)**：
     - 單一按鈕「團隊與發布」（附帶未讀訊息紅點）。
     - 點開下拉選單展示：
       - 團隊即時討論室 (Team Chat)
       - 團隊成員與角色權限 (RBAC)
       - 發布為獨立代管網站 (Hosted Micro-App)
       - 空間 QR Code 與邀請連結
  4. **主行動按鈕**：「+ 新增工具」（鮮明手帳珊瑚色）
  5. **更多選項 (`...`)**：包含「AI 代寫」、「大螢幕投影」、「空間設定」
  6. **日夜模式 (Sun/Moon) + 頭像**
- **效果**：所有文字標籤均有充裕空間，絕無文字擠壓跑位問題。

### 步驟 3：卡片頭部圖示降噪與標題字樣空間釋放 (`ToolCard.jsx`)
- **常駐保留（僅 2 顆控制項）**：
  - 左側：拖曳把手（若具編輯權限）+ 完整小工具標題（釋放 80% 寬度，標題清晰易讀，絕不被擠爛）+ 輕量類型小圓點。
  - 右側：**全螢幕聚焦 (Maximize)** + **更多動作 (`...`)**。
- **收納至 `...` 更多動作下拉選單**：
  - 便箋紙質色彩 (Pastel colors)
  - 編輯小工具代碼 (Pencil)
  - 尺寸寬度切換 (1x / 2x)
  - 獨立浮動視窗彈出 (Pop-out)
  - 置頂釘選 (Pin)
  - 發布為獨立代管網站 (Share2)
  - 建立副本 (Duplicate) / 複製到其他空間
  - 匯出小工具 JSON
  - 刪除小工具 (Trash)
- **高頻動作**（重新整理、編輯）亦支援懸停顯現 (Hover Reveal)，平時不干擾閱讀。
