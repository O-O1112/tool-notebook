# 工具小本本 (Tool Notebook) - 第二階段進階實用功能擴充計畫

為讓「工具小本本」更加靈活強大，規劃實作第二階段五大深具生產力價值的高階功能。

---

## 提案功能清單

### 1. 🧰 精選實用工具範本庫升級至 10 款 (Expanded Templates)
將範本庫從 5 款倍增至 10 款高品質純前端工具，全面涵蓋日常辦公、開發輔助與團隊協作：
- 📝 **Markdown 即時筆記器**：雙欄即時預覽、代碼高亮、一鍵複製與匯出。
- 🔐 **安全密碼與隨機金鑰產生器**：自訂長度、大小寫、數字、特殊符號、強度檢測與一鍵複製。
- 🔍 **JSON 格式化與校驗檢視器**：排版格式化、單行壓縮、語法錯誤檢查。
- 🌍 **世界時區時鐘與時間換算**：台北、東京、倫敦、紐約時區即時對照。
- 📊 **字數統計與 Base64/URL 編碼器**：即時字數/字元/行數統計，支援快速編解碼。
- （原有 5 款保持：番茄鐘、抽籤轉盤、多色便箋、極簡塗鴉白板、標準計算機）。

### 2. 🪟 獨立浮動視窗彈出 (Pop-out Detached Window)
- 在工具卡片頂部新增「**彈出獨立視窗 ↗**」功能。
- 點擊後可將任意小工具以純淨獨立的瀏覽器視窗彈出，方便拖曳至副螢幕、懸浮於桌面側邊進行多工操作。

### 3. 🌓 多款紙質視覺風格主題切換 (Paper Themes)
在導覽列新增主題快速切換功能（即時套用並自動記住）：
- **方眼米紙 (Warm Grid)**：經典 28px 格紋、溫暖米白（預設）。
- **深邃夜墨 (Night Ink)**：質感深灰黑底、沉靜柔和、夜間護眼。
- **復古牛皮 (Vintage Kraft)**：溫潤棕褐牛皮紙質。
- **簡約素白 (Clean Minimal)**：無格紋乾淨極簡風。

### 4. 📌 工具置頂釘選 (Pin to Top)
- 允許將最常用的核心工具「釘選至最頂端」，顯示精美珊瑚色圖釘標記，不受排序干擾。

### 5. 🏷️ 工具標籤與分類篩選 (Tags & Tag Filter)
- 新增與編輯工具時支援輸入自訂標籤（例如：`日常`, `開發`, `工作`, `待辦`）。
- 頂部搜尋列自動提取所有現有標籤，點擊標籤即可一鍵過濾對應工具。
