# 路線 A 執行計畫：Canva 式「無程式碼個人數位手帳」全面轉型

本計畫依據使用者決策「路線 A（Canva 式無程式碼個人數位手帳與儀表板）」，針對系統先前「不踏實、心智模型割裂、技術詞彙生硬、新空間空洞無感」等核心痛點，進行產品定位、介面語彙、新手落地體驗與可靠度架構的深度重構。

---

## 1. 核心變更目標

1. **全面脫工程化（去代碼感）**：
   - 徹底清除使用者可見介面中的「Iframe」、「自訂 HTML/JS 程式碼」、「沙盒容器」、「Token 隔離」等開發者術語。
   - 全面替換為「手帳工具組」、「智慧文具」、「便箋隨筆」、「嵌入小視窗」等溫潤直覺的手帳語言。
2. **新手空間落地「踏實感」（開箱即用文具套件）**：
   - 建立新空間時，預設勾選「預先裝入生活與學習手帳文具套件」。
   - 新空間誕生即內建 3 款開箱即用的經典手帳工具：
     - **番茄專注鐘**（25分鐘高效工作與滴答白噪音）
     - **隨手便利貼**（自動本機儲存、多色切換的今日筆記）
     - **每日打卡習慣卡**（直觀簡明的日常習慣追蹤）
   - 徹底消滅「一進空間一片死寂白茫茫」的空洞感，讓使用者第一秒就能操作、感受手帳溫度。
3. **新增工具流程以「手帳文具庫」為第一公民**：
   - 「新增小工具」彈窗預設展示分類清晰的 23 款手帳工具卡片（番茄鐘、便利貼、計算機、塗鴉板、字數統計等），一鍵加入手帳。
   - 「自訂代碼」降級為次要的「自創工具 / 外部連結嵌入」，提供友善範例說明，降低技術門檻。
4. **過濾列與卡片標籤純淨化**：
   - `SpaceLayout.jsx` 的次級過濾列標籤由 `自訂程式 / Iframe 視窗` 改為 `全部 / 手帳工具 / 嵌入視窗`。
   - `ToolCard.jsx` 的卡片類型徽章由 `自訂程式` 升級為溫潤的 `手帳工具`。
5. **離線與跨裝置穿透可靠性**：
   - 確保所有預載工具與範本在任何網路環境（包含無伺服器連線、無痕模式）皆能 100% 秒開運行，杜絕白屏與轉圈。

## 3. 實施步驟

### 步驟 1：建立新空間預載手帳文具機制
1. 修改 `CreateSpaceModal.jsx`，加入 `preloadStationeryKit` 勾選狀態（預設 `true`）。
2. 在 `App.jsx` 的 `handleCreateSpace` 內，當 `preloadStationeryKit === true` 時，依序批次呼叫 `api.addTool` 加入：
   - 番茄工作法計時鐘（效能與專注）
   - 快速便利貼與便箋（筆記與備忘）
   - 每日習慣打卡清單（生活日常）
3. 讓新空間載入完成後立即具備 3 個完整工具，版面飽滿、立即能用。

### 步驟 2：全站語彙脫工程化與去代碼感
1. 清查 `ToolCard.jsx`，將 `getTypeName` 的輸出映射改為：
   - `html` -> `手帳工具`
   - `iframe` -> `嵌入視窗`
   - `url` -> `網頁小卡`
2. 清查 `SpaceLayout.jsx`，過濾列按鈕對應為 `全部`、`手帳工具`、`嵌入視窗`。
3. 清查 `AddToolModal.jsx`，標籤頁更名為：
   - 分頁一：`精選手帳文具 (開箱即用)`
   - 分頁二：`自創手帳工具 (網頁或代碼)`
   輸入提示與說明文字全面去掉「HTML/JS 片段」、「Iframe Tag」，改為白話且友善的提示。

### 步骤 3：Navbar 與分享選單親和化
1. 調整 `Navbar.jsx`：
   - 「發布獨立代管微應用」更名為「發布專屬手帳微應用」。
   - 「模式 1 / 2 / 3」說明改為生活化情境：「全螢幕單一小工具」、「多分頁手帳入口」、「嵌入個人 Notion / 筆記」。
   - 空間邀請碼改為「手帳專屬密碼」。

### 步驟 4：自動化測試與無 Emoji 驗證
1. 執行 `npm test` 確保既有 44 項測試全數通過（必要時更新測試中的字串斷言）。
2. 執行無 Emoji 掃描腳本，確保零 Emoji 違規。
3. 執行 `npm run build` 驗證生產打包。
4. 同步更新 `docs/walkthrough/route_a_solid_stationery_notebook_walkthrough.md`。

## 4. 驗證與驗收標準

1. **使用者進入點測試**：
   - 點擊「建立新手帳空間」，預設勾選預裝套件。
   - 建立完成進入空間後，畫面立即陳列番茄鐘、便利貼、打卡卡片，點擊番茄鐘開始計時、在便利貼打字，數據順暢運作。
2. **語彙與心智模型檢視**：
   - 全站無任何突兀的「自訂程式」、「Iframe」標籤，全數以溫潤的「手帳工具」、「嵌入視窗」呈現。
3. **無 Emoji 與代碼規範**：
   - 全站無任何表情符號，圖示全數採用 Lucide React。
