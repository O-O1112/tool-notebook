# 實作計畫：分離「介紹主頁」與「工具主頁」雙首頁架構

為解決目前系統缺乏產品介紹與展示首頁、未登入直接被強制卡在登入框、無法讓訪客與使用者隨時切換「產品功能介紹」與「小工具管理工作區」的架構問題，本計畫規劃完整的雙首頁架構。

---

## 1. 架構決策與方案評估

### 方案比較
- **方案 A（推薦）：單頁 SPA 動態視圖切換（`landing` 與 `dashboard` 雙首頁）**
  - **機制**：在 React 狀態中納入 `currentView: 'landing' | 'dashboard' | 'space'`，並同步至網址參數（`?view=landing` 與 `?view=dashboard`）。
  - **優點**：
    - 切換零延遲、無需重新加載頁面，狀態與主題（日間/深色）完美保持。
    - 兼容 GitHub Pages 靜態託管（避免前端路由刷新 404）。
    - 訪客可於「介紹主頁」直接操作微應用互動範例，點擊「免登入體驗 Demo」即刻無縫跳轉「工具主頁」。
  - **方案 B：多頁面 HTML 分割（`index.html` 與 `dashboard.html`）**
    - **缺點**：重新加載頁面造成閃爍、靜態託管配置繁複、登入狀態跨頁同步成本高。

---

## 2. 核心功能規劃

### A. 介紹主頁 (`LandingView.jsx`)
1. **頂部導覽列**：
   - 品牌標誌與「工具小本本」名稱。
   - 快速切換按鈕：高亮「介紹主頁」，可隨時切換至「工具主頁」。
   - 右側行動鍵：若已登入顯示「進入工具主頁」與使用者稱謂；若未登入顯示「登入 / 註冊」與「免登入體驗 Demo」。
2. **Hero 視覺震撼區**：
   - 標語：專為自訂代碼、外部嵌入與微應用打造的高質感手帳空間。
   - 三大行動呼籲（CTA）：一鍵開啟工具主頁、免登入體驗 Demo、探索三大代管模式。
   - **即時可操作微應用互動預覽**：內嵌一個真實可互動的小工具卡片（如番茄鐘/計數器），讓訪客第一秒就能感受到沙盒的流暢度。
3. **四大核心特色亮點**：
   - **三大獨立代管模式**：模式 1 全螢幕、模式 2 客製分頁、模式 3 雙欄對照。
   - **嚴密沙盒安全隔離**：隔離主視窗儲存區，支援純網址與 HTML 自訂代碼。
   - **團隊三人協作與 RBAC**：擁有者、協作者、檢視者，邀請碼加入與討論室。
   - **手帳質感文具與簡報展示**：5 大佈局與 Shift+P 投影簡報。
4. **微應用範本展示專區**：精選小工具卡片展示（計時器、文字轉譯、健康計算等）。
5. **三大模式互動模擬切換**：在介紹頁提供模式 1、2、3 的動態切換示意。
6. **頁尾 Footer**：快速返回頂部、進入工具主頁等連結。

### B. 工具主頁 (`SpaceDashboard.jsx` + `Navbar.jsx`)
1. **導覽列整合**：
   - 在空間大廳模式的 Navbar 左側，加入清晰的視圖切換標籤：
     - `介紹主頁`（點擊切換至 Landing）
     - `工具主頁`（當前啟動中）
2. **免登入進入保護**：
   - 若訪客在未登入狀態下從介紹頁點擊「工具主頁」，彈出 `LoginModal` 或提供「一鍵以體驗帳號快速進入」，大幅降低體驗門檻。

### C. 登入彈窗化 (`LoginModal.jsx`)
- 將原先全螢幕阻斷式的 `LoginCard` 包裝為浮動彈窗，使用者在介紹頁點擊登入時不會被突然切換頁面，維持優雅流暢的手帳體驗。

---

## 3. 實作步驟

1. 建立 `src/client/components/LoginModal.jsx`。
2. 建立 `src/client/components/LandingView.jsx`（含手帳風格、互動範例、三大模式介紹）。
3. 修改 `src/client/components/Navbar.jsx`：在大廳狀態加入「介紹主頁」與「工具主頁」切換分段按鈕。
4. 修改 `src/client/App.jsx`：
   - 支援 `currentView: 'landing' | 'dashboard' | 'space'`。
   - 調整未登入時預設呈現「介紹主頁」，點擊登入彈出 `LoginModal`。
   - 網址參數同步與切換邏輯。
5. 驗證與測試：`npm test` 與 `npm run build`。
