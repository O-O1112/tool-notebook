# 手繪風情境插畫與全景天際線成果報告

依據使用者需求與手帳溫潤質感設計參考，已全面在空間大廳、工具清單與頁面底部導入**原生向量 SVG 手繪風情境插畫（Illustrations）**，賦予無資料或特定情境時更具溫度與童趣的視覺體驗。

---

## 🎨 核心手繪插畫組件庫 ([`Illustrations.jsx`](file:///C:/Users/liguo/.gemini/antigravity/scratch/edu-embed-space/src/client/components/Illustrations.jsx))

所有插畫均以**純向量 SVG** 實現，不依賴任何外部圖床或額外網路請求，並全方位適配日間紙質與深邃夜墨模式（線條與填色自動隨主題變數切換）：

### 1. 資源回收桶：小熊閱讀與整齊收納箱 (`TrashEmptyIllustration`)
- **設計場景**：參考設計原型，戴著珊瑚色毛線球冬帽的小熊，坐在收納整齊的木桌抽屜與搬家紙箱堆上安詳閱讀，身旁有綠意盎然的龜背芋盆栽、復古鵝黃折疊檯燈、書包行囊與桌底嫩芽。
- **應用位置**：空間大廳「資源回收桶」空狀態。
- **文案呼應**：「您尚未將任何手帳空間丟入垃圾桶 / 最近刪除的手帳空間將會列在此處，隨時可以安全還原。」

### 2. 我的最愛：天文望遠鏡眺望星辰 (`FavoritesEmptyIllustration`)
- **設計場景**：三腳架天文望遠鏡眺望夜空彎月、金黃十字星宿與星光軌跡，左側小木桌上放著裝滿閃爍心願金星的玻璃罐與珍藏手帳本。
- **應用位置**：空間大廳「我的最愛」空狀態。
- **文案呼應**：「尚無已加星號的手帳空間 / 點擊任何空間卡片右上角的 ⭐ 星號，即可將常用空間收入我的最愛。」

### 3. 全新空間創作：手帳手作書桌 (`SpacesEmptyIllustration`)
- **設計場景**：攤開的方眼排版手帳本，熱氣裊裊的手沖咖啡馬克杯、斜插沾水鋼筆與刻度直尺的文具筒、彩色紙膠帶捲與靈感火花。
- **應用位置**：空間大廳「由我建立」與「最近使用」空狀態。
- **文案呼應**：「您尚未建立任何手帳空間 / 立即點擊按鈕建立您的第一個主題手帳空間，開啟靈活工作看板！」

### 4. 他人共享：紙飛機與協作郵箱 (`SharedEmptyIllustration`)
- **設計場景**：兩架帶著卡片的摺紙紙飛機在雲朵間迴旋交會，帶著愛心信封飛往古樸協作郵筒，傳遞共創的美好。
- **應用位置**：空間大廳「他人共享」空狀態。
- **文案呼應**：「尚無他人共享的手帳空間 / 輸入同伴分享的邀請碼即可共同協作，隨時激盪靈感！」

### 5. 搜尋無結果：探索手帳的放大鏡 (`SearchEmptyIllustration`)
- **設計場景**：放大的手繪鏡片透視翻開的手帳，浮動著金色小問號與探索星塵。
- **應用位置**：空間大廳關鍵字搜尋無結果、小工具清單搜尋無結果。

### 6. 空間尚無工具：設計畫架與創意積木 (`ToolsEmptyIllustration`)
- **設計場景**：立體的畫架木架，上面放著虛線空白畫布，周圍漂浮著 HTML 代碼積木、Iframe 地球儀、手帳調色盤與水彩筆。
- **應用位置**：手帳空間內部尚無任何小工具時。

### 7. 底部漫遊天際線：全景童話城市景緻 (`PanoramicSkyline`)
- **設計場景**：參考原型的浪漫全景城市浮水印，橫跨全螢幕底部，包含摩天輪、歐風尖頂小木屋、聯排市集、拱門石橋、書本山丘、松樹林、宏偉大鐘樓、熱氣球、凱旋門、筆尖尖塔、水車與海岸燈塔。
- **應用位置**：空間大廳底部背景裝飾。
