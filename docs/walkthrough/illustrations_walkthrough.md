## 🎨 手繪插圖與微型飾紋組件總覽 ([`Illustrations.jsx`](file:///C:/Users/liguo/.gemini/antigravity/scratch/edu-embed-space/src/client/components/Illustrations.jsx))

所有插畫皆採用純向量 SVG 繪製，不依賴外部圖床或圖片請求，支援深淺色主題自動自適應（`currentColor` 與 CSS 變數）：

### 一、 空間卡片專屬封面手繪飾紋 (`CoverDoodle`)
針對 6 款手帳主題色系與回收桶狀態，繪製專屬微型手繪插圖，浮動於卡片頂部封面：
1. **主題 0 (珊瑚蜜桃)**：手繪桃花花苞、熱氣茶杯與書籤絲帶。
2. **主題 1 (薄荷松綠)**：龜背芋盆栽、多肉仙人掌與澆水嫩芽。
3. **主題 2 (天峰蔚藍)**：翱翔雲端的摺紙紙飛機、虛線飛行軌跡與星星。
4. **主題 3 (薰衣草紫)**：夜空新月、魔幻羽毛沾水筆與星座星宿。
5. **主題 4 (晨曦暖黃)**：溫暖微笑朝陽、復古雙耳小鬧鐘與咖啡。
6. **主題 5 (典雅焦糖)**：旅行者復古雙眼相機、指南針刻度與戳印標章。
7. **回收桶專用**：木質置物籃、待整理信箋與重生小葉片。

### 二、 核心操作與欄位插畫
1. **建立空間專屬畫架 (`CreateSpaceDoodle`)**：
   - 空白木製畫架、畫布中心的溫暖加號與金黃靈感星芒。
   - 應用於：空間大廳末尾「建立新手帳空間」虛線引導卡片，取代單調圖標。
2. **側邊欄微型藏書架 (`BookshelfDoodle`)**：
   - 木質層架、整齊直立手帳、傾斜筆記本、可愛小仙人掌盆栽與金屬書擋。
   - 應用於：側邊欄底部「手帳工作空間」配額卡片。
3. **貨架空欄位收納籃 (`EmptyShelfBasketDoodle`)**：
   - 編織收納籃搭配拖曳導引箭頭與色彩微粒。
   - 應用於：貨架分欄模式（Shelf Layout）當該欄位尚無任何工具時的置物引導。
4. **登入迎賓手帳茶席 (`LoginWelcomeIllustration`)**：
   - 展開的雙頁手帳本（含書籤帶、方格打勾筆記）、熱氣裊裊的愛心馬克杯、斜臥鋼筆與靈感星芒。
   - 應用於：登入/註冊卡片頂部，大幅提升初次接觸的溫暖手作氛圍。
5. **資料備份檔案收納箱 (`BackupArchiveDoodle`)**：
   - 掀蓋木質公文檔案箱、標籤資料夾與同步箭頭。
   - 應用於：空間設定「資料備份與 JSON 封裝」資訊卡。
6. **手帳紙質調色盤飾紋 (`ThemePaperDoodle`)**：
   - 疊放方眼格米紙、復古牛皮紙與水彩毛筆。
   - 應用於：偏好設定「手帳紙質風格底色」選取區塊。

### 三、 六大情境空狀態插畫
1. **資源回收桶 (`TrashEmptyIllustration`)**：毛線帽小熊在書桌與收納箱堆上安靜閱讀。
2. **我的最愛 (`FavoritesEmptyIllustration`)**：天文望遠鏡仰望夜空星辰與許願星玻璃罐。
3. **建立空間 (`SpacesEmptyIllustration`)**：方眼手帳、手沖咖啡、直尺文具筒與彩色紙膠帶。
4. **他人共享 (`SharedEmptyIllustration`)**：紙飛機與協作郵筒。
5. **搜尋無結果 (`SearchEmptyIllustration`)**：透視手帳的放大鏡。
6. **尚無工具 (`ToolsEmptyIllustration`)**：畫架、HTML 積木與調色盤。
7. **全景天際線 (`PanoramicSkyline`)**：橫跨全寬之歐風小鎮摩天輪與書山天際線。
