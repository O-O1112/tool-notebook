# 功能擴充變更記錄：20 款離線小工具、全域快捷指令面板與投影簡報模式

本階段已成功為「工具小本本」完成深度實用功能擴充，包含擴充至 20 款 100% 離線可用純前端工具範本、全域快捷指令面板（Command Palette）以及大螢幕投影簡報模式（Presentation Mode）。

---

## 核心交付項目

### 1. 擴充 5 款純前端離線高質感小工具範本（累計 20 款）

所有小工具範本均符合零外部依賴、純演算法與標準 Web API、100% 離線可用原則，並嚴格遵循無表情符號規範：

1. **色彩調色盤與對比檢查器 (`color-palette`)**：
   - 支援 HEX / RGB / HSL 即時互轉。
   - 根據 WCAG 2.1 標準計算前景與背景相對亮度（Relative Luminance）與對比度比率。
   - 具備 AA / AAA 級文字可讀性評級提示。
2. **艾森豪四象限時間管理法 (`eisenhower-matrix`)**：
   - 重要且緊急、重要不緊急、不重要但緊急、不重要不緊急 4 大維度分類收納。
   - 支援勾選完成、即時刪除與 localStorage 本機持久化。
3. **Web Audio 專注節拍器與調音笛 (`metronome`)**：
   - 支援 40 至 240 BPM 寬廣拍速調節與常用速度預設點擊（Andante、Moderato、Allegro、Presto）。
   - 支援 2/4、3/4、4/4、6/8 拍號切換與動態第一拍重音、視覺拍點跳動。
   - 內建標準 440Hz A4 音準調音笛，透過 Web Audio API 純演算法合成，無需任何音訊檔下載。
4. **離線客製 QR Code 產生器 (`custom-qrcode`)**：
   - 純 JavaScript 矩陣演算生成，無須外部網路請求。
   - 支援自訂前景色彩與背景色彩、Canvas 畫布高清渲染與一鍵 PNG 下載。
5. **現代字體排版視覺對比器 (`typography-tester`)**：
   - 支援經典排版比例（Minor Third、Major Third、Perfect Fourth、Golden Ratio）字級級距計算。
   - 即時調節字級、行高（Line-height）、字距（Letter-spacing）。
   - 提供即時可編輯樣稿與一鍵複製 CSS 代碼片段。

## 2. 全域快捷指令面板 (Global Command Palette)

- **呼叫方式**：全域監聽鍵盤快捷鍵 `Ctrl + K` / `Cmd + K`，或點擊導覽列上的「搜尋...」按鈕。
- **功能特點**：
  - **跨空間即時切換**：模糊搜尋所有已建立與共享的空間，Enter 一鍵無縫載入。
  - **當前空間工具聚焦**：即時索引當前工作區的所有工具，選取後畫面平滑滾動並標記聚焦高亮邊框。
  - **版型與外觀切換**：快速將當前空間切換為貨架分欄、瀑布流、網格、分頁或折起模式；快速切換日間溫潤紙質與深邃夜墨深色模式。
  - **快速操作**：快速開啟新增小工具、建立新空間、匯出空間備份 JSON 等常用動作。
  - **流暢鍵盤操作**：支援方向鍵上下導航、Enter 執行、Esc 退出。

---

## 3. 大螢幕投影簡報模式 (Big-Screen Presentation Mode)

- **呼叫方式**：快捷鍵 `Shift + P` 切換，或點擊頂部工具列「投影簡報」按鈕；按 `Esc` 或 `Shift + P` 隨時退出。
- **展示特性**：
  - 自動隱藏頂部 Sticky 導覽列與工作區搜尋/標籤篩選列，消除所有非必要干擾。
  - 在卡片視圖中自動隱藏編輯、刪除、拖曳把手、顏色選單與置頂釘選等管理控件，僅保留小工具操作介面、重新整理與獨立全螢幕按鈕。
  - 於畫面右上角提供極簡浮動控制膠囊，具備「投影簡報模式中」狀態標記、日夜間主題切換（因應投影機對比亮度調節需求）與一鍵退出按鈕。
