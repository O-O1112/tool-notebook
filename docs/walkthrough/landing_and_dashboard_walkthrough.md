# 介面極簡化重構、代管載入修復與認證文案專業化記錄

本文件記錄針對使用者反映的畫面繁雜、字彙重疊錯位、代管載入卡死與文案口語化等痛點進行之架構升級、效能與視覺優化成果。

---

## 1. 核心問題診斷與修復

### 1.1 代管微應用白屏卡死 (圖一修復)
- **現象**：訪問 `?host=HOST-XXXX` 時，畫面中央永久轉圈顯示「載入小工具…」，無法正常互動。
- **根本原因**：`SandboxedFrame.jsx` 以 `srcDoc` 載入記憶體 HTML 時，部分 Chromium / Safari 引擎在 React 註冊 `onLoad` 前已完成內部 DOM 解析，合成事件未如期捕獲，導致 `loading` 狀態永遠卡在 `true`。
- **架構修復**：
  - 引入安全探測與 600ms 自動逾時回退機制（若 `iframe.contentDocument.readyState === 'complete'` 則 80ms 內退場）。
  - 無論沙盒程式碼複雜度如何，載入遮罩必定在 600ms 內平滑退場，徹底杜絕無限轉圈。

### 1.2 發布成功提示對比度不足 (圖二修復)
- **現象**：發布結果橫幅底色與文字色彩對比過低，文字淡薄模糊。
- **架構修復**：
  - 重構 `PublishModal.jsx` 發布成功橫幅，採用高對比翡翠綠卡片配色（`bg-emerald-50/90 dark:bg-emerald-950/40`）。
  - 標題與說明文字採用深色翡翠墨綠（`text-emerald-950 dark:text-emerald-100`），專屬代碼以獨立膠囊襯底突顯，符合 AAA 級無障礙閱讀標準。

### 1.3 裝飾插圖重疊覆蓋文字與排版錯亂 (圖三修復)
- **現象**：自訂程式按鈕上方重疊圓形封蠟印章，文字「自」被圖案蓋住造成字形錯亂。
- **根本原因**：過濾列外層容器掛載了 `absolute right-4 top-1` 的 `SpaceStationeryBannerDoodle`，在不同解析度折行時物理覆蓋了右側操作項。
- **架構修復**：
  - 徹底移除該處衝突的裝飾微插圖。
  - 清查所有字元符號，將純文字符號（如 `✕`、`✓`）全數替換為正規語意化 Lucide 圖示（`<X size={12} />`、`<Check size={14} />`）。

### 1.4 工具列按鈕重複與畫面繁雜擁擠 (圖四修復)
- **現象**：頂部導覽列與次級過濾列重複出現「發布代管」、「團隊成員」、「團隊對話」、「AI 代寫」、「投影簡報」等 5 組按鈕，同時出現兩組搜尋框。
- **架構修復**：
  - **極簡頂部導覽列**：將協作功能整合為單一「團隊與發布」下拉選單；擴充功能收錄於「更多動作（...）」選單。
  - **次級過濾列權責分離**：專注負責工具卡片過濾（全部、自訂程式、Iframe 視窗）、範本專區入口與批次選取管理，消除所有重複按鈕與干擾元素。

### 1.5 深度對齊 Canva 產品設計哲學 (UX & IA 重構)
- **Canva 標誌性「分享 (Share)」單一入口中心**：
  - 將導覽列原先冗贅的「團隊與發布」按鈕，正式重構為 Canva 風格的高質感「分享 (Share)」按鈕。
  - 將發布代管（模式 1/2/3）、團隊成員權限與邀請碼、空間 QR Code、討論室全數收斂於該入口，消除畫面雜訊。
- **Canva 經典「你可能想嘗試…」大廳範本快速啟用推薦列**：
  - 在空間大廳（Dashboard）首頁頂部，直接呈現熱門微應用卡片帶（番茄鐘、便利貼、計算機、Markdown、密碼產生器）。
  - 提供即時「試玩」與「以此建空間」一鍵建立按鈕，使用者無需四處翻找即可秒速開啟生產力。
- **去除口語化體驗詞彙**：全站清除「免登入體驗 Demo」與「demo1234」等不成熟字樣。
- **正式化行動按鈕 (CTA)**：
  - 官網首頁 Header：未登入提供「登入」與「免費註冊」；已登入提供「進入工作空間」。
  - Hero 視覺區：主行動按鈕為「免費開始使用」，次級行動按鈕為「探索三大代管模式」與「瀏覽範本專區」。
  - 沙盒預覽：標題規範為「互動預覽：番茄工作法計時鐘」，底欄引導為「無需安裝任何本機環境，輸入或匯入代碼即可安全運行」與「立即建立您的手帳」。
  - 點擊註冊直接呼叫具備 `defaultIsRegister` 參數的高質感模態登入卡片，視線不跳轉，操作流暢連貫。
