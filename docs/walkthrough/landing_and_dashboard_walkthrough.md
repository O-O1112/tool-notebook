# 雙首頁架構升級記錄：分離「介紹主頁」與「工具主頁」

本記錄彙整針對系統升級「介紹主頁 (Landing / Feature Showcase)」與「工具主頁 (Tools Dashboard / 空間大廳)」雙首頁架構之具體實作與驗證結果。

---

## 1. 升級背景與設計

- **升級前問題**：
  - 訪客訪問站點若未登入，直接被強制卡在登入卡片，無法了解產品功能、獨立代管模式與範本庫。
  - 登入後的使用者缺乏產品特色導覽頁面，無法隨時回顧功能解說或探索三大代管模式。
- **雙首頁架構**：
  1. **介紹主頁 (`landing`)**：
     - **公開存取**：訪客與已登入使用者皆能直接訪問。
     - **頂部導覽列**：品牌識別、雙首頁切換分段膠囊（`[介紹主頁]` / `[工具主頁]`）、章節平滑捲動（三大代管模式、核心特色、精選範本、常見問題）。
     - **Hero 視覺區**：產品定位標語、CTA 按鈕（開啟工具主頁、免登入體驗 Demo、探索三大代管模式）。
     - **即時可操作微應用沙盒**：首頁右側直接內嵌真實運行的「番茄鐘計時器」沙盒，訪客第一秒即可動手點擊試玩。
     - **三大獨立代管模式切換**：模式 1 全螢幕獨立運行、模式 2 指定多工具 + 客製分頁、模式 3 雙欄對照 / 外部嵌入。
     - **四大特色與範本預覽**：安全沙盒隔離、5 款排版、團隊協作 RBAC、大螢幕投影簡報。
  2. **工具主頁 (`dashboard`)**：
     - 空間大廳工作區：管理所有空間、收藏夾、封存、回收庫、建立新空間。
     - 導覽列左側常態提供 `[介紹主頁]` 與 `[工具主頁]` 切換膠囊，點擊可秒切。
  3. **彈窗化登入體驗 (`LoginCard`)**：
     - 未登入訪客在介紹頁點擊「登入 / 註冊」時，以優雅浮動 Modal 呈現，不中斷當前瀏覽視線。
     - 點擊「免登入體驗 Demo」時，自動登入體驗帳號並無縫跳轉工具主頁。

## 2. 異動檔案清單

1. `src/client/components/LandingView.jsx`：全新打造的手帳風格產品介紹主頁。
2. `src/client/components/LoginCard.jsx`：擴充支援 `isModal`、`onClose` 與 `onSuccess` 彈窗模式。
3. `src/client/components/Navbar.jsx`：大廳模式新增「介紹主頁」與「工具主頁」分段切換按鈕。
4. `src/client/App.jsx`：納入 `currentView: 'landing' | 'dashboard' | 'space'` 路由狀態與網址參數同步。
