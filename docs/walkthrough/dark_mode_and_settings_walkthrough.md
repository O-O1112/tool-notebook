# 深色模式色彩階調調校成果

針對深色模式（Dark Mode）中**部分色彩過於刺眼突出**、**部分文字與控制項不明顯**的問題，已完成全面重構與視覺調校。

---

## 🎨 改善核心對比與問題修復

### 1. 消除「太突出 / 刺眼」區塊 (Eliminating Glaring Blocks)
- **手帳空間卡片封面改用低彩度寶石墨色 (`cover-theme`)**：
  - 原先卡片封面使用 inline style 強制填入日間粉彩（蜜桃粉、薄荷綠、天峰藍等），在深色背景下有如強光色塊；現抽離為 `cover-theme-0` ~ `cover-theme-5` 與 `cover-theme-trash` 類別。
  - 深色模式下自動切換為**沈穩雅緻的低飽和寶石墨色底紋**（如暗酒紅 `#271e1c`、薄荷夜墨 `#162421`、深海藍 `#16212e`、冷夜紫 `#221a2d`、焦糖炭 `#241c18`），搭配微弱柔和的白紋方格線，大幅降低視覺刺激。
- **作用中膠囊與頭像背景半透明溫潤化**：
  - 全面修正原本未適配深色的日間色塊（如 `bg-[#fff9f6]`、`bg-[#fff4f0]`、`bg-[#fff5f2]`），改以柔和的半透明珊瑚底色（`rgba(225, 123, 98, 0.15)`）呈現，不再像發光的白色貼紙。
- **次級徽章與計數器白底調和**：
  - `bg-white/70`、`bg-white/80`、`bg-white/90` 在深色模式下統一轉換為低彩暗夜玻璃材質（`rgba(36, 44, 56, 0.88)`），與卡片渾然一體。

---

### 2. 解決「不明顯 / 辨識度低」問題 (Enhancing Indistinct Elements)
- **次要文字與說明文字對比度提升**：
  - `--muted` 變數自 `#8a96a4` 提升至 `#9eabb8`（WCAG 對比度 > 6:1），空間說明、副標題不再灰暗模糊。
  - `--faint` 自 `#4c5765` 提升至 `#657487`，拖曳把手與輔助標籤清晰可辨。
  - `text-[#57767f]`（Navbar 返回大廳、使用者標籤）在深色模式下對應提升至明亮柔和的 `#9cb1b8`。
- **彩色功能標籤在深色環境下亮度調優**：
  - 綠色功能與鑰匙圖示（`text-[#3b827e]`）轉換為清透明亮的薄荷綠 `#4fd1c5`。
  - 我的最愛文字（`text-amber-600`）轉換為亮琥珀金 `#fbbf24`。
  - 資源回收桶（`text-red-600`）轉換為柔和粉紅珊瑚 `#f87171`。
- **按鈕懸浮（Hover）互動防消失修正**：
  - 修復原本在深色模式下 hover 時文字變為 `#1f2a2e`（暗黑墨色導致圖示隱形）的缺陷，統一修正為高對比白亮色 `#f0f6fc`。
  - 移除 hover 時閃現白底的問題，改為細緻微光半透明層（`rgba(255, 255, 255, 0.08)`）。
- **Navbar 佈局切換器作用中狀態強化**：
  - 作用中按鈕由原先與背景幾乎無異的暗灰色，強化為 `#27313f` 配亮珊瑚橘文字 `#f08b73`，一眼即可辨識目前處於哪種排版模式。
- **工具清單標籤「全部」按鈕**：
  - 改用動態主題色彩變數 `bg-[var(--ink)] text-[var(--paper)]`，在深色模式下展現清晰的白底黑字膠囊，不再與背景融為一體。
