# 深色模式 (Dark Mode) 與整合設定區開發成果

針對使用者反映深色切換時畫面突兀（白底橫幅、白底導覽列、黑字被暗底吞沒等問題），本次更新全面重構深色模式架構，修復所有黑白視覺衝突，並將分散的調節項目收攏至統一的「設定區」。

---

## 核心升級重點

### 1. 頂部導覽列一鍵切換深色模式 (`Navbar.jsx`)
- **單鍵切換 (Sun / Moon 🌞/🌙)**：
  - 整合於導覽列右側（大廳模式與空間模式皆可使用）。
  - 具備記憶還原機制：切換至深色（深邃夜墨）時，自動記錄當前選用的手帳紙質（如方眼米紙、復古牛皮或簡約素白）；再次切換為日間模式時，精確復原使用者先前的紙質設定。
- **全域設定按鈕**：
  - 將原先浮動的 Palette 色盤下拉選單移除，替換為統整的 `Settings` 齒輪按鈕，無論在大廳或空間內皆可隨時呼叫設定面板。
- **導覽列暗色底色**：
  - 改用 `bg-[var(--card-bg)]/90`，不再強制 `bg-white/90`，深色模式下呈現深邃半透明玻璃擬態質感。

### 2. 全域深色模式視覺適配 (`notebook.css` & `SpaceDashboard.jsx` & `SpaceLayout.jsx`)
- **徹底修復截圖問題**：
  - **空間大廳迎賓橫幅**：加上 `.dashboard-banner` 專屬暗色樣式，不再呈現刺眼純白巨型方塊。
  - **大廳空間卡片**：卡片文字全面套用 `var(--ink)` 與 `var(--muted)`，卡片底層改為 `#1c222b` 深色紙質，邊框改用 `var(--line)`，標題清晰銳利，不再黑字吃進黑底。
  - **虛線新增卡片**：圖示外框改為 `var(--card-bg)`，文字高對比呈現。
  - **便箋調色盤低彩度護眼化**：針對 `.theme-dark` 重新調校蜜桃、薄荷、檸檬、天峰藍與薰衣草之便箋色彩，降低刺眼亮度，提升暗黑閱讀舒適度。
  - **空間工作區工具列與分欄**：`SpaceLayout` 工具列改用 `var(--card-bg)`，分欄貨架底色自適應暗色紙質。

### 3. 全新整合式設定中心 (`SpaceSettingsModal.jsx`)
- **外觀與風格調節分頁 (Appearance Tab)**：
  - **明暗模式快速切換**：提供「日間手帳模式」與「深邃夜墨模式」雙大卡片選擇。
  - **手帳紙質底色挑選**：方眼米紙、復古牛皮、簡約素白三種風格，附色票圓點與手帳紙質說明。
  - **預設排版模式偏好**：貨架分欄、緊湊瀑布流、網格並排、分頁輪播、折起專注直接於設定區切換。
- **空間管理分頁 (Space Info Tab)**：
  - 空間名稱、描述備註修改、邀請碼顯示。
- **資料備份分頁 (Data Backup Tab)**：
  - JSON 工具備份下載與匯入。
- **危險操作分頁 (Danger Zone)**：
  - 刪除空間二次確認。
