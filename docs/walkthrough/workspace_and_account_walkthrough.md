# 工作區側邊欄大廳與個人帳號設定中心升級成果

已完成依照使用者參考樣式全面重構空間大廳首頁為**側邊欄工作區（Sidebar Workspace Dashboard）**、建置**旗艦級 6 頁籤系統設定中心**（支援個人暱稱修改、明暗紙質、空間管理、資料備份、系統安全與危險操作），以及實現**我的最愛（⭐ 星號）與資源回收桶（🗑️ 軟刪除與還原）**分類機制。

---

## 🚀 核心升級項目與亮點

### 1. 側邊欄工作區大廳 (`SpaceDashboard.jsx`)
- **左側邊欄（Left Sidebar）**：
  - **使用者迎賓名片**：展示個人頭像、顯示暱稱（`您好，{displayName}`），以及根據星期幾動態計算的迎賓問候（如 `週六快樂！`）。
  - **空間即時搜尋**：提供手帳空間名稱、描述及邀請碼之即時篩選。
  - **5 大核心導覽分類**（支援即時徽章數量統計）：
    - 🕒 **最近使用**（Recent）：依最新開啟時間遞減排序。
    - 🧩 **由我建立**（Owned）：專屬由自己創建之手帳空間。
    - 👥 **他人共享**（Shared）：由同伴透過邀請碼共享之協作空間。
    - ⭐ **我的最愛**（Favorites）：一鍵加星號之常用空間集合。
    - 🗑️ **資源回收桶**（Trash）：被移至垃圾桶之已封存空間（完全與常規檢視隔離）。
  - **快捷行動按鈕**：
    - `+ 建立新空間`：彈出主題空間建立對話框。
    - `加入他人空間`：輸入 SPC-XXXX 邀請碼加入空間。
  - **底部配額指示卡片**：手帳空間配額狀態與自由創作提示。
- **右側主工作空間（Main Workspace）**：
  - **頂部狀態與排序切換**：顯示當前分類標題、空間總數，以及「修改日期」與「名稱 A-Z」即時排序按鈕。
  - **莫蘭迪手帳風格卡片**：
    - 多彩封套飾紋與排版標籤（貨架分欄、緊湊瀑布流、網格並排、分頁輪播、折起專注）。
    - 右上角 ⭐ 加星號快捷按鈕（已加入者呈現亮眼琥珀金）。
    - 獨立浮動下拉選單（分享 QR Code、空間設定、移至回收桶）。
    - 回收桶檢視專用操作：直接提供「還原空間」與「永久刪除」按鈕。
  - **客製化親切空狀態卡片**：針對我的最愛、回收桶、他人共享與自建空間提供專屬說明與引導按鈕。
  - **底部手繪風天際線浮水印 Line Art**：以典雅手繪線條筆觸呈現巴黎與書本天際線浮水印，營造手帳工藝氛圍。

### 2. 個人帳號管理與即時更名 (`SpaceSettingsModal.jsx` & `AuthContext.jsx`)
- **API 端點升級**：
  - Node.js Express：新增 `PATCH /api/auth/profile`。
  - Cloudflare Worker：新增 `PATCH /api/auth/profile`。
  - 支援更新 `display_name`，並重新簽發包含最新暱稱的 JWT Token。
- **客戶端即時同步**：
  - `AuthContext.updateProfile({ displayName })`：呼叫 API 成功後，即時更新上下文狀態、`localStorage ('class_notebook_user')` 與 JWT Token，所有迎賓詞、導覽列與卡片即時同步變更。
- **導覽列直達**：
  - 點擊頂部導覽列個人身分名牌，可直接開啟設定中心並定位至「個人帳號」頁籤。

### 3. 旗艦級系統設定中心 (Comprehensive Settings Center)
全方位擴充為 6 大標準化功能頁籤：
1. 👤 **個人帳號 (Account)**：頭像名片預覽、唯讀使用者名稱、可編輯顯示暱稱（附儲存按鈕與成功提示）、身分徽章，以及安全登出按鈕。
2. 🎨 **外觀與風格 (Appearance)**：日間手帳 vs 深邃夜墨模式切換卡、3 款手帳紙質底色（方眼米紙、復古牛皮、簡約素白），以及空間排版偏好調節。
3. 📁 **空間管理 (Space Info)**：空間名稱修改、空間備忘說明修改、邀請碼顯示。
4. 📄 **資料備份 (Backup & Data)**：一鍵匯出全空間小工具為標準 JSON 檔案（含 HTML/JS、Iframe 配置、色票便箋、置頂與分欄），以及 JSON 備份檔反向匯入。
5. ℹ️ **關於系統 (About)**：版本號 v2.2.0、100% 嚴格安全隔離沙盒聲明（Iframe Sandbox 杜絕 XSS 與跨站隱私竊取）、常用操作捷徑小提示。
6. ⚠️ **危險操作 (Danger Zone)**：永久刪除空間雙重防護確認按鈕。
