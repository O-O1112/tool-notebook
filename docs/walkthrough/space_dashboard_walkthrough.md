# 主頁空間大廳 (Space Dashboard) 開發成果

將「工具小本本」由原先單一空間直接展示，升級為具備空間大廳導覽結構的兩層式工作區架構：主頁可瀏覽與挑選空間，點擊進入後才是工具內容。

---

## 核心功能與變更一覽

### 1. 空間主頁大廳 (`SpaceDashboard.jsx`)
- **迎賓看板與統計**：展示使用者專屬問候語、空間總數統計與快速「+ 建立新空間」、「加入空間」入口。
- **分類頁籤篩選**：
  - **全部空間**（All）
  - **我建立的**（Owned）：具備空間擁有者橘色徽章
  - **他人共享**（Shared）：顯示分享者名稱與藍色共享徽章
- **即時關鍵字搜尋**：即時依空間名稱、備註說明與空間邀請碼 (`SPC-XXXX`) 進行快速模糊檢索。
- **空間卡片牆**：
  - **虛線引導卡**：大尺寸 "+ 建立新空間" 提示卡，支援懸浮微動效。
  - **彩色幾何紋理封面**：自動循環五種莫蘭迪粉彩條紋封面（蜜桃、薄荷、天峰藍、薰衣紫、暖陽）。
  - **佈局識別徽章**：直接標示各空間目前採用的排版（貨架分欄、瀑布流、網格、分頁輪播、折起專注）。
  - **更多操作 (`⋯`) 浮動選單**：直接在卡片上產出 QR Code、一鍵複製邀請碼、進行設定備份或刪除空間。修復 `.dashboard-cover` 與卡片 `z-index` 防止選單被遮蔽或裁切。
  - **防文字擠壓保護**：空間擁有者標籤設定 `truncate max-w-[110px]` 與箭頭圖標 `shrink-0`，防止卡片縮小時字彙與圖示重疊。

### 2. 獨立建立空間對話框 (`CreateSpaceModal.jsx`)
- 提供空間名稱輸入、說明備註選填。
- 提供 5 種預設佈局可視化卡片選單（貨架分欄預設選取、緊湊瀑布流、網格並排、分頁輪播、折起專注）。
- 修正版面與圖示對齊：貨架分欄使用 `Kanban` 看板圖示；緊湊瀑布流使用 `Columns3` 多欄自適應圖示。
- 建立成功後自動載入該空間並跳轉進入空間工作區。

### 3. 頂部導覽列情境適應 (`Navbar.jsx`)
- **大廳模式 (`currentView === 'dashboard'`)**：
  - 左側展示「工具小本本」品牌與「主頁大廳」標章。
  - 右側展示「加入空間」、「建立新空間」、手帳紙質主題切換器與使用者帳號資訊。
- **空間內容模式 (`currentView === 'space'`)**：
  - 左側提供「← 返回大廳」按鈕（修正響應式斷點 `hidden sm:inline` 與 `whitespace-nowrap`，不再異常遮蔽或折行）與空間切換下拉選單。
  - 保留當前空間邀請碼標籤與一鍵複製/重產。
  - 右側保留完整的五種佈局切換器（修正貨架分欄與瀑布流圖示對應）、手帳主題切換、QR Code 分享、設定與「+ 新增工具」。

### 4. 文字與圖標重疊修復 (`notebook.css`, `SpaceDashboard.jsx`, `SpaceLayout.jsx`, `AddToolModal.jsx`)
- **搜尋輸入框文字與放大鏡圖示重疊修復**：
  - **根因分析**：`.notebook-input` 在 `notebook.css` 中設定 `padding: 10px 14px;`，因宣告順序晚於 Tailwind，覆蓋了 Tailwind 的 `pl-8` 類別，導致輸入框文字自左側 14px 起始，直接與左側 12px~26px 的 `<Search>` 放大鏡圖示重疊。
  - **解決方案**：新增專屬 `.notebook-input-search`（`padding-left: 36px !important; padding-right: 32px !important;`），確保文字與放大鏡圖示之間保留 10px 舒適間距，並預留右側清除按鈕空間；同時將圖示加上 `pointer-events-none` 與 `shrink-0`，點擊圖示直接聚焦輸入框。
- **模態視窗按鈕排版**：
  - 新增 `.notebook-btn-xs` 與 `.notebook-btn-sm` 樣式規格，透過 `!important` 確保緊湊按鈕內距固定（`padding: 4px 8px`、`white-space: nowrap`）。
  - 徹底解決「新增工具」範本卡片在窄寬度下，按鈕內「預覽」、「微調代碼」、「加入」等中文字被 CSS 預設大按鈕 padding 擠壓成單字折行（如「預」/「覽」）與圖示碰撞之問題。
- **工具卡片 (`ToolCard.jsx`) 與大廳卡片**：
  - 標題與類型標籤加入 `shrink` 與 `truncate` 保護，在緊湊視窗下類型文字響應式隱藏、只留圖示，確保拖曳握把與操作按鈕群組永遠排版工整無重疊。

### 5. 路由與瀏覽器歷史同步 (`App.jsx`)
- 透過 `window.history.pushState` 與 `popstate` 監聽，支援原生瀏覽器「上一頁 / 下一頁」直覺切換：
  - 進入空間：網址更新為 `?space=ID`
  - 訪客分享：網址維持 `?share=SPC-XXXX`
  - 返回大廳：清除參數恢復乾淨網址
- 重新整理時自動記憶目前所在空間，無額外依賴第三方路由庫，無縫相容 GitHub Pages 靜態託管。
